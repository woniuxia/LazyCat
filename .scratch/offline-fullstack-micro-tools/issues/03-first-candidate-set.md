## Question

基于已确定的高频口径和维护边界，首批应评估哪些独立微工具？请确定候选集合、每项解决的具体日常问题、离线差异价值、首版范围和明确非目标。

## Answer

首批候选集合冻结为两个新工具，不设最低数量，上限为五个；只有出现明确的高频场景才追加候选。当前工具目录中的能力只作为重复能力和可复用基础设施参考，不重新纳入本路线图。

### 异常堆栈整理器

- 日常问题：粘贴 JavaScript/TypeScript 或 Java 的异常堆栈，提取异常类型、消息、文件路径和行列号，生成可复制的排查摘要。
- 离线差异价值：堆栈可能包含内部路径和业务信息，整个解析过程无需上传第三方服务。
- 首版范围：支持上述两类明确的常见堆栈格式；无法识别时保留原文并明确提示。
- 非目标：实时日志采集、源码映射、在线符号解析和 APM。

### 文本编码与换行诊断器

- 日常问题：定位乱码、BOM、`CRLF/LF` 混用和不可见字符，并预览常见编码转换结果。
- 离线差异价值：直接处理本地文本和代码文件，不依赖在线转换或上传内容。
- 首版范围：检测 UTF-8、UTF-16 BOM 与常见换行符，提供明确的转换结果预览。
- 非目标：无 BOM 文本的绝对准确编码猜测、IDE 替代能力和所有历史代码页覆盖。

集合选择遵循横向覆盖、单点输入输出和可独立退出原则；候选通过“核心路径必须离线完成”门槛后，按使用频率优先排序。X.509 证书检查、数据库连接串解析、日志脱敏与格式化、语义版本计算和 Git 忽略规则测试因当前使用价值不足，不进入首批。
