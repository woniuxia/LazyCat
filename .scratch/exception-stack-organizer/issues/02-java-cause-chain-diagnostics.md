# 02 — Java 异常链与有界诊断

**What to build:** 在已有 JavaScript/TypeScript 解析闭环上，用户可以处理普通 Java 异常及其原因链，并清楚看到格式判断、识别边界和摘要截取规则，不会因异常链或缩写帧丢失证据。

**Blocked by:** 01 — JavaScript/TypeScript 异常堆栈解析闭环

**Status:** ready-for-agent

- [ ] 普通 Java 异常头、`Class.method(File.java:line)` 调用帧、`Caused by` 原因链和 `... N more` 省略帧信息可被结构化展示。
- [ ] 工具能在 JavaScript/TypeScript 与 Java 之间自动识别，也允许用户手动覆盖；歧义或不支持的输入会明确展示诊断，不静默套用默认格式。
- [ ] 多个互不相关的根异常不会被合并；部分可识别输入保留已找到的结果，同时单独展示未识别行和解析诊断。
- [ ] 所有可识别帧按原文顺序收集，从输入末尾向前选取全局最多五帧，再按原始顺序展示，并明确报告省略数量。
- [ ] 原因链与调用帧分区展示，规范化摘要和结构化结果使用同一份解析结果；解析和面板行为有覆盖上述边界的定向测试。
