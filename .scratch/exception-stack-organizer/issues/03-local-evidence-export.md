# 03 — 本地证据导入与摘要交付

**What to build:** 用户可以把本地文本堆栈载入异常堆栈整理器，明确复制或另存为规范化摘要，并在失败、清空和窄窗口场景下保持原始证据与当前状态可理解。

**Blocked by:** 01 — JavaScript/TypeScript 异常堆栈解析闭环

**Status:** ready-for-agent

- [ ] 用户可以通过现有本地文件能力选择文本文件作为原始输入；打开、解析和取消操作均由用户显式触发，打开文件不会隐式修改或覆盖源文件。
- [ ] 规范化摘要可以显式复制；复制成功与剪贴板失败都向用户展示真实结果，不伪造成功状态。
- [ ] 用户必须选择明确的新保存目标才能另存为摘要；保存失败可见，源堆栈文件不会被覆盖。
- [ ] 清空操作会同时重置原文、结构化结果和诊断；解析失败时保留当前原文并清理本次尝试产生的派生结果。
- [ ] 长输入、空态、错误态和窄窗口下原文、结果、诊断与操作入口不重叠且可访问；行为测试覆盖文件打开、复制、另存为、清空、失败反馈和不持久化内容。
