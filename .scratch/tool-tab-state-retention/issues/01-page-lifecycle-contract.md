## Question

当工具标签页仍然打开但暂时不可见时，页面的挂载、激活、停用和销毁分别应遵循什么行为？需要覆盖输入、滚动位置、焦点、弹窗/浮层、事件监听、轮询、计时器、编辑器实例和未完成操作等边界，并明确哪些后台行为必须暂停、哪些必须继续。

## Answer

### 页面生命周期契约

- 每个仍打开的工具标签页保留一个页面实例；切换到其他标签页只让该实例失活，不重新执行首次挂载和初始化。
- 输入内容、滚动位置、选中项、编辑器实例和未完成的页面编辑状态在失活期间保留。
- 失活页面不再拥有焦点和当前交互权；临时弹窗、浮层、上下文菜单等依赖当前交互的 UI 在失活时关闭或失效。
- 页面私有的键盘/鼠标监听、轮询、周期刷新和重型可视化在失活时暂停，重新激活时恢复；普通数据重新激活时是否刷新由“非活动数据刷新”工单单独定义。
- 关闭标签页、关闭其他、关闭左侧或关闭右侧会销毁对应页面实例，但销毁页面不自动取消应用级长任务或停止应用级服务。

### 应用级运行边界

以下能力脱离工具页面运行，切换或关闭对应标签页不会中断，必须通过领域自身的显式停止/取消入口结束：

- 上线包打包、动作中心组合动作、网络访问链路诊断。
- 请求转发规则、API Mock 服务、桌面挂件和 Inbox 剪贴板采集。
- 番茄钟会话、Vault 自动锁定与敏感信息安全计时。

Todo 提醒调度、应用级剪贴板监控和离线手册服务属于已有的应用基础设施，也不受工具标签页生命周期影响。

页面只承担这些运行状态的展示和操作。任务状态、进度、日志、结果及取消能力必须由应用级运行状态或后端服务持有；重新打开工具时重新连接到当前运行状态。
