Type: grilling
Status: resolved

## Question

如何定义“页面没有重新刷新”的可验收证据和最低回归范围？需要覆盖普通输入型工具、异步加载工具、带滚动/选中状态工具、PM 内部视图、带轮询或全局监听工具，以及标签页关闭和批量关闭后的资源释放。

## Answer

### 验收定义

“页面没有重新刷新”定义为：同一 Tab 页面实例在切换前后保持连续，首次挂载和初始化不会重复发生；用户可见状态、未保存编辑和未完成的页面级单次操作不因切换丢失或重复启动。外部数据按非活动数据刷新契约处理，不把“保持实例”误解为永远不更新外部数据。

### 最低回归范围

- 普通输入型工具：输入未保存内容并生成预览，切换多个 Tab 后返回，输入和派生结果保持不变。
- 异步加载工具：在操作进行中切换 Tab，返回后只存在一次操作，成功结果或错误结果正常收口；连续启动新操作时旧响应不能覆盖新状态。
- 滚动与选择：设置滚动位置、筛选条件和选中项，切换后保持这些局部浏览状态；允许外部数据轻量刷新但不能重置浏览上下文。
- PM 内部视图：覆盖列表、详情、项目或内部视图切换，验证外层 Tab 缓存不会破坏 PM 自己的局部状态保留。
- 轮询与全局监听：页面失活后页面级轮询、定时器和监听暂停或释放，重新激活不会重复注册；应用级服务仍按既定契约继续运行。
- 关闭与批量关闭：关闭单个 Tab、关闭其他、关闭左侧和关闭右侧后，对应页面实例和页面级资源释放一次；已销毁页面不再接收异步回写，应用级任务不因页面关闭被取消。

### 验收证据

- 组件或集成测试记录挂载/销毁次数、操作调用次数和监听/定时器注册与清理次数，证明切换没有隐式重建或重复资源。
- 代表性工具补最小端到端或手工冒烟，直接检查输入、滚动、选择、异步结果和关闭行为；截图只能作为辅助，不能替代生命周期证据。
- 类型检查和渲染层构建作为交付门槛，但不能替代上述行为验收。
- 不覆盖应用重启后的 Tab 恢复，也不要求每一个普通纯本地工具都单独增加一套生命周期测试。
