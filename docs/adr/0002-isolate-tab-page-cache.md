# 每个工具标签页使用独立页面缓存宿主

工具标签页按 `tab.id` 各自拥有独立页面宿主和 `KeepAlive` 边界，切换时停用页面实例，关闭时通过卸载宿主精确销毁缓存。该结构取代全局动态包装组件、`KeepAlive.include` 名单和手工组件 Map，避免缓存淘汰依赖 Vue 的名称匹配规则，同时不采用让所有工具页面持续挂载和活动的 `v-show` 方案。

外层页面视口属于标签页宿主，内部滚动区域属于被缓存的页面实例；两者都依靠 DOM 连续性保留滚动位置，不建立全局滚动状态仓库。页面级资源按需直接使用 Vue 的 `onActivated` 和 `onDeactivated` 暂停与恢复。
