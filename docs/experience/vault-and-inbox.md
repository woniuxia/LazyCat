# Vault 与 Inbox 经验

适用范围：密码库会话、安全显示、Spotlight 搜索、收纳箱采集与跨工具草稿。

关键词：`vault`、`inbox`、`clipboard capture`、`session`、`Spotlight`

## Vault 会话与显示分离

失焦只隐藏敏感信息，不销毁已解锁会话；真正锁定与 UI 遮罩分开建模。分级锁定优先复用现有会话和设置通道，避免再造第二套密码状态。

## 仅加密敏感字段

Vault 当前只对密码等敏感字段加密，账号等可检索元数据保持结构化，以支持 Spotlight 按账号查询。任何扩展都要同时审查搜索可见性与敏感信息泄露边界。

## Inbox 采集抑制

剪贴板采集、图片预览和“回采”是不同状态。应用自己写回剪贴板时设置一次性抑制，避免刚复制出的内容再次进入 Inbox；暂停和隐藏时采集遵循明确设置。

## 跨工具草稿

Inbox 向 Todo、Vault 等工具流转时传递显式草稿，不直接写入目标业务表；目标面板负责让用户确认和保存。
