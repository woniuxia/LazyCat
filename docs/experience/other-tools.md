# 其他工具经验

适用范围：尚不足以独立成域的工具与通用纯函数模式。

关键词：`JsonTreeViewer`、`Base64`、`snippets`、`text`、`pomodoro`

## 通用 JSON 树遍历留在纯函数层

搜索定位、路径解析、复制、编辑与撤销依赖同一套节点遍历规则。规则放在 `src/utils` 并由多个消费方复用，组件只维护展开、选中和编辑状态。

## Base64 自动识别与手动偏好分离

自动识别是输入事实，用户手动选择是偏好；自动同步不能反写手动状态。识别、校验和转换放纯函数，面板负责交互编排。

## 代码片段检索与三栏状态

片段内容、目录选择、检索结果和编辑 dirty 状态独立建模；批量动作明确目标集合。FTS 是派生检索能力，不替代原始片段事实。

## 番茄钟触发与倒计时分离

后台负责真实触发时间，前端倒计时只是显示。窗口休眠或渲染暂停后按绝对时间重算，不累计 interval 漂移。

## SQL 实体字段排除

基类字段、表字段映射和生成注解是独立配置；生成前在结构化字段层排除，不在最终字符串上做脆弱替换。

## 首版工具补齐工作流

高收益工具首版除了 happy path，还要补输入校验、复制/清空、错误反馈、状态持久化和定向测试；不要用静默默认值制造伪成功。
