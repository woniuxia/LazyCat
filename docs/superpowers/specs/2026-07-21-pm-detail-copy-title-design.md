# 项目管理工作项详情标题复制设计

## 目标

优化项目管理工作项详情面板的标题区域：编号与标题使用一致的文字样式，并允许用户直接点击整行标题复制“编号 + 标题”。

## 交互设计

- 编号和标题继续显示在同一标题行内，编号不再使用较小字号、较轻字重或等宽字体，而是继承标题的字体、字号、字重和颜色。
- 整个标题行使用无边框文本按钮承载，视觉上保持标题形态，不增加复制图标或额外操作按钮。
- 鼠标悬停时整行使用轻微的主题色反馈并显示可点击光标；键盘聚焦时显示清晰焦点态。
- 点击或通过键盘激活标题时，将内容写入系统剪贴板。
- 存在编号时复制格式为 `<编号> <标题>`，中间使用一个半角空格；没有编号时仅复制标题。
- 复制成功后提示“已复制编号和标题”；复制失败时提示“复制失败”。

## 实现范围

- 仅修改 `apps/desktop/src/components/pm/PmDetailPanel.vue` 的标题模板、复制逻辑和局部样式。
- 新增对应的组件源码测试，验证标题使用可交互语义、编号继承标题样式、复制文本格式及反馈逻辑。
- 不修改工作项数据结构、后端接口、其他项目管理视图或 Todo 详情页行为。

## 边界处理

- `refCode` 为空、缺失或仅包含空白时，复制内容不保留多余空格，仅复制标题。
- 标题较长时继续自动换行；交互容器占满可用宽度，不改变详情面板宽度。
- 剪贴板写入异常必须显式提示，不吞掉错误。

## 验证

1. 先运行新增测试并确认在实现前因缺少复制交互而失败。
2. 实现后运行新增测试与相关 PM 前端测试。
3. 运行 `pnpm typecheck`。
4. 运行 `pnpm --filter @lazycat/desktop build:web`。
