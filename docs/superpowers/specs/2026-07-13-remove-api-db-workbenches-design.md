# 移除接口调试与数据库工作台设计

## 背景与结论

LazyCat 当前内置的“接口调试”和“数据库工作台”已经形成两个专业客户端级子系统，但目前没有实际使用者。继续维护需要长期投入 HTTP 协议、认证、响应预览、数据库驱动、方言兼容、查询安全和复杂交互等工作，且难以形成相对于成熟专业工具的优势。

本次决定完整移除这两个功能。API Mock、HTTP 状态码、SQL 转实体、SQL 格式化、密码库数据库凭据等独立能力继续保留。

产品边界调整为：LazyCat 优先提供高频、离线、即开即用的原子开发工具，不再内置需要持续追赶专业客户端的深度工作台。

## 删除范围

### 接口调试

- 删除 `api-workbench` 的工具目录入口和异步组件注册。
- 删除前端面板、子组件、类型、composable、纯函数及对应测试。
- 删除全部 `tool:api-workbench:*` IPC 通道。
- 删除 Rust `api_workbench` 模块、action 分发、数据表初始化和兼容迁移。
- 删除仅供该功能使用的响应缓存、历史、集合、环境变量和标签页相关运行逻辑。

### 数据库工作台

- 删除 `db-workbench` 的工具目录入口和异步组件注册。
- 删除前端面板、数据库子组件、类型、composable、纯函数及对应测试。
- 删除全部 `tool:db:*` IPC 通道。
- 删除 Rust `db`、`db_drivers` 模块、action 分发、连接池、查询取消和数据表初始化逻辑。
- 删除仅供数据库工作台使用的数据目录迁移和 `db-key` 处理逻辑。
- 从 Rust 依赖中移除仅供该功能使用的 `sqlx` 和 `redis`，同步更新锁文件。

### 明确保留

- API Mock 的前后端、测试、文档和历史记录。
- `ureq` 及其被网络工具、API Mock 等其他功能使用的能力。
- Monaco、JSON 树、格式化工具等共享组件与工具函数。
- Vault 的加密能力和密码库中的数据库类型条目。
- HTTP 状态码、SQL 转实体、SQL 格式化等原子工具。

删除共享代码前必须先确认没有其他消费方，不能因名称或历史来源相近而连带删除。

## 数据策略

本次不执行任何破坏性数据清理：

- 已有安装中的 `api_workbench_*`、`db_connections`、`db_saved_queries`、`db_query_history` 等表不执行 `DROP TABLE`。
- 不主动删除已有 `db-key`、接口响应缓存目录或 `user_settings` 中的接口调试标签状态。
- 新安装不再创建相关数据表，新版本也不再读写这些遗留数据。
- 不提供导出和迁移流程，因为当前确认没有实际使用者。

遗留数据可以在未来单独设计可确认、可回退的清理功能；本次删除不扩大到用户磁盘数据清理。

## 文档清理

- 删除仅描述接口调试或数据库工作台的旧设计文档、实施计划和修复设计。
- 删除 `process.md` 中仅描述这两个功能开发、修复和重构的历史章节。
- 对 JSON 树、结构治理、IPC 契约等共享文档，只移除与已删除功能有关的内容，不删除仍服务其他功能的文档和工程经验。
- API Mock 相关设计文档和 `process.md` 记录保持不变。
- 本文档作为移除决策和边界的唯一保留记录。

## 实施顺序

1. 移除前端目录入口、注册、面板和专属代码。
2. 移除 bridge 通道、Rust 模块注册和后端实现。
3. 移除相关 schema 初始化、迁移和数据目录联动逻辑，但不增加删除旧数据的迁移。
4. 移除 `sqlx`、`redis` 依赖并更新锁文件。
5. 清理旧设计、实施计划、`process.md` 历史章节和共享文档中的过期引用。
6. 全仓搜索遗留标识并完成验证。

## 验证

必须完成以下检查：

- 活跃源码中不再存在 `api-workbench`、`api_workbench`、`db-workbench`、数据库工作台 IPC 通道或模块注册。
- `sqlx`、`redis` 不再出现在直接 Rust 依赖中。
- API Mock 和其他共享能力仍能编译并通过测试。
- 执行 `pnpm test`。
- 执行 `pnpm typecheck`。
- 执行 `pnpm --filter @lazycat/desktop build:web`。
- 执行 `cargo test`。
- 执行 `cargo check`。

本次不启动产品 UI，不执行数据库表、缓存目录、密钥文件或设置项的数据清理。

## 非目标

- 不增加新的接口调试或数据库替代功能。
- 不新增外部工具启动器或数据导出能力。
- 不删除 API Mock。
- 不改造其他工具的视觉或交互。
- 不清理用户磁盘上的历史数据。
