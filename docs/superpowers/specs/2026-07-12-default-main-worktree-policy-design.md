# 默认 main 分支与 worktree 使用约束设计

## 目标

在项目级代理规范中明确：非必要不使用 Git worktree，默认直接在 `main` 分支修改，减少小任务因隔离工作区带来的流程成本和 Windows 清理问题。

## 修改方案

- 在 `AGENTS.md` 与 `CLAUDE.md` 的 `07.1 默认执行原则` 同步增加一条规则。
- 两份文件使用完全一致的文案：

> 非必要不创建或使用 Git worktree；默认直接在 `main` 分支修改。仅当用户明确要求隔离、存在并行修改冲突风险，或任务流程明确强制要求隔离时，才使用 worktree。

## 边界

- 不在 `02.2 Agent 决策闸门` 重复添加检查项。
- 不改变现有高风险操作、dirty worktree、防破坏性操作和验证规则。
- 当用户明确要求或已启用的任务流程明确强制 worktree 时，以更具体的指令为准。

## 验证

- 检查 `AGENTS.md` 与 `CLAUDE.md` 的新增文案完全一致。
- 检查两份文件的章节结构和相邻规则未发生变化。
- 检查 `git diff --check` 通过。
